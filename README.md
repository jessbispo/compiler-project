# 🐞 MINIPASCAL COMPILER PROJECT
This project consists on the implementation of a **MiniPascal** compiler, following the traditional compilation process through Lexical Analysis, Syntactical Analysis, Semantic Analysis, Intermediate Code Generator, Independent Machine Code Optimizer, Code Generator and Dependent Machine Code Optimizer. Plus, during the compilation process, the Table of Symbols and Error Handling structures are used to manage errors and maintain consistency.
